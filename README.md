# Help-Desk Application 🛠️

A robust **Node.js** backend system designed to manage and streamline college support requests. This project features dedicated routes for users and administrators to handle complaints, feedback, and ticket tracking.

## 🚀 Features
* **Multi-Role Routing:** Separate logic for `admin`, `user`, and `chatbot` interactions.
* **Ticket Management:** Functional pages for viewing pending, resolved, and spam tickets.
* **Node.js Backend:** Powered by Express, utilizing `cors` for cross-origin connectivity and `nodemon` for development.
* **Database Integration:** Includes a `seedUsers.js` script for initial data setup.

## 🛠️ Technology Stack
* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, JavaScript
* **Development Tools:** Nodemon, Git

## 📋 Prerequisites
Before running the project, ensure you have **Node.js** installed on your machine.
